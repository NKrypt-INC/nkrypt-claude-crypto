# Security Policy

## Supported Versions
This project is in beta (v0.4.1-beta). We support the latest release for security fixes.

## Reporting a Vulnerability
We take security seriously and appreciate your help! Do **not** open public issues for vulns. Use private channels to avoid exposing exploits.

### Preferred: GitHub Private Reporting
Submit via our secure form: https://github.com/[your-org]/crypto-claude-code-marketplace/security/advisories/new  
(You'll need a GitHub account; we'll respond within 48 hours.)

### Alternative: Email
info@nkrypt.com  
- Include: Description, affected files/versions, repro steps (redact secrets), and impact.  
- GPG encryption encouraged (public key: [paste key or link if available]).  
- Expect acknowledgment in 48 hours; we'll coordinate disclosure (e.g., 90-day embargo).

## Our Process
1. **Acknowledge**: Confirm receipt and classify severity.  
2. **Triage**: Assess + discuss privately (1-7 days).  
3. **Fix**: Patch in a private branch/PR.  
4. **Disclose**: Public advisory + CVE (if applicable) after verification.
