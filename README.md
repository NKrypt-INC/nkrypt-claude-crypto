# nkrypt-claude-crypto marketplace

Status: **beta** (v0.5.0-beta). Treat outputs as triage and engineering playbooks, not a security audit.


This repository contains a Claude Code marketplace bundle with a single plugin: **crypto**.

It focuses on practical, production-oriented cryptography:
- classical crypto hardening (passwords, AEAD, TLS, RNG, key management)
- multi-language implementation examples (Node.js, Python, Go, Java, .NET, Rust)
- testing checklists with runnable patterns
- secrets scanning and rotation playbooks
- post-quantum readiness and measured hybrid migration planning

It aims to help teams fix today's common crypto failures first, then plan PQC transitions with interoperability and operational reality in mind.

## Installing

Use this repository as a Claude Code marketplace source (see Claude Code docs for marketplace bundles).

## Plugins included

- `crypto`  
  Full-spectrum cryptography guidance: audit, secure implementation, passwords, TLS, secrets scanning, PQC migration planning, testing, operations, and compliance notes.
